## 2025-05-18 - Empty State Pattern
**Learning:** Empty states are opportunities for delight and recovery. Using specific icons (like `SearchX` for search failures and `PackageOpen` for empty lists) combined with clear, actionable buttons ("Clear Search", "View All") significantly improves the user experience compared to plain text.
**Action:** When implementing lists or grids, always consider the "zero data" state and provide a path forward (e.g., clear filters) rather than a dead end. Use `animate-in` classes for a smoother entrance.
