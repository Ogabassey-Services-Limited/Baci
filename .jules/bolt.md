## 2024-05-24 - FlatList getItemLayout Optimization
**Learning:** In React Native, `FlatList` components without explicit sizes rely on asynchronous UI thread measurements, which can cause significant jank and layout jumping during rapid scrolls. While text-heavy/dynamic lists cannot safely use `getItemLayout` due to wrapping, fixed-height lists (like bank selection pickers with static padding/font layouts) often omit this optimization unnecessarily, hindering performance on mobile devices.
**Action:** Always calculate and assign deterministic `getItemLayout` parameters (including margin/padding) to `FlatList` components rendering static-height items to bypass the React Native measurement path entirely, reducing CPU load and preventing offset corruption.
