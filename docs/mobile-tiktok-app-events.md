# TikTok App Events SDK

The mobile iOS apps use the official `TikTokBusinessSDK` CocoaPod through the local `@baci/tiktok-business` Expo module. The module initializes the SDK from iOS `Info.plist` values generated by the package config plugin during `expo prebuild`.

## Storefront

- App Store ID: `6472735367`
- TikTok App ID: `7644522796883296263`
- Required release secret: `STOREFRONT_TIKTOK_APP_SECRET`

## Admin

- App Store ID: `6757810806`
- Required release secrets:
  - `ADMIN_TIKTOK_APP_ID`
  - `ADMIN_TIKTOK_APP_SECRET`

## SKAN

TikTok SKAdNetwork support stays enabled by default. Set `STOREFRONT_TIKTOK_DISABLE_SKAN=1` or `ADMIN_TIKTOK_DISABLE_SKAN=1` only if another SDK or MMP is responsible for SKAN conversion value updates.

## Debug Mode

Set `TIKTOK_SDK_DEBUG=1` only for test builds. TikTok debug/test events are not production reporting events.
