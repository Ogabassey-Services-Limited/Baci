# Ogabassey current origin baseline

No baseline has been captured by this tooling commit. Operational Gate A, after merge, must inventory only the merchant's discovered hostnames (at minimum `ogabassey.com`, `www.ogabassey.com`, and `ogabassey.usebaci.com`), retain seven closed UTC days of redacted bounded aggregates, and record DNS proxy/certificate/redirect/cache and Vercel runtime attribution evidence.

It must separately calculate anonymous-document origin misses, alias/dynamic origin rates, reducible Vercel cost, Worker/R2/Analytics/Logs/traces cost, required Transform Rule cost, and conservative payback. Percentage-only or apex-only evidence is not a baseline. Missing host inventory, attribution, quota/entitlement clarity, positive savings, or owner-approved horizon is `NOT_PROVEN` or `STOP`; it is never permission to route production traffic.
